# Jade Snowpulse AI — Documentation

AI-powered Snowflake account health checks, cost governance, and query
optimization — running entirely inside your own Snowflake account via
Snowpark Container Services, with Snowflake Cortex as the only AI backend.
No external API keys, no data leaving your account.
